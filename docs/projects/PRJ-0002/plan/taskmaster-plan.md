## S1 出口：M1 走查脚本（13 步）

注册 3 任务图（建表→接口→测试）→ 计划卡确认派建表 → 模拟卡死标 stalled 报人 → 人裁 resume → 交卷验收过 → 自动出下一批计划卡派接口 → 证据缺失拒收打回 → 补齐过 → 派测试 → 图完成 → 关开关零 spawn → 投递失败回滚留痕 → 暂停/停止/注销走查 → kill 应用重验续调（不重复、不跳步、在途重挂）。
