# <需求池名 / 项目名> 需求文档

（说明：本文件是 **PRD 的上游**。PRD 回答「选中的这个功能做什么」，本文回答「这些诉求本身成立吗、凭什么排在前面、哪些已经决定不做」。**需求池不只装活下来的需求**——被拒的、延期的、合并的都要在这里留痕，否则三个月后没人知道为什么没做。编号约定：`R-x`（本文）→ `FR-x` / `NFR-x`（PRD）。）
